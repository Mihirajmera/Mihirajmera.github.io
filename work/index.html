Where each tool sits in an AI system

An AI agent is an identity with tokens, a model it trusts and servers it calls. Each tool governs one part of that system and produces evidence for it. Select a label to open the tool.

  1. AI agent → MCP servers
    Governed by agent-access-review: who owns the agent, what it can reach, and whether that's approved.
  2. AI agent → Model
    Governed by llm-redteam-evidence: can the model be hijacked, and is this release worse than the last?
  3. Data and egress
    Where both meet: an agent that reads sensitive data and can send it out is flagged as an exfiltration path.
