Open-source AI GRC tools

AGENTIC AI · ACCESS GOVERNANCE

agent-access-review

User access reviews for AI agents. It reads MCP configs (Claude Desktop, Cursor, VS Code) and agent manifests, inventories what each agent can read, write, execute and send, and tests it against 12 controls.

  • Flags unowned agents, stale approvals, over-broad scopes, plaintext secrets and dormant access, like an ITGC access review.
  • Detects exfiltration paths: agents that read sensitive data, ingest attacker-controlled content and can send data out.

AI SECURITY · AI ASSURANCE

llm-redteam-evidence

Turns LLM red-team results from garak and promptfoo into audit evidence. Every attack maps to a control with a documented risk tolerance and a 95% confidence bound.

  • Release gate: blocks a new model version that's measurably easier to attack than the approved one.
  • Hashed evidence tied to the raw tool output, plus OSCAL results for GRC platforms.
